## Draft text

### Research Question 4: Which candidate substitutions target the cost mechanisms of the priority components?

Each substitution was chosen to address the reason its component wastes energy, not only the component's name. An initial set of candidates for the attention core, the attention projections, the embeddings and layer normalization was fixed before profiling, so that each could be measured in the same session as the baseline. Once the profile had identified the priority components, each was checked for a matched candidate. Positional encoding, which had none, received two: the same rotary computation compiled into fused kernels, and its removal. Layer normalization received a fused version of its substitute after the first full profiling run showed that RMSNorm written as separate operators cost more energy than LayerNorm, so that the effect of the algorithm could be separated from that of its implementation. Candidates for components that are not priorities are kept as comparisons. Table 9 lists the matches, the cost mechanism each candidate addresses, whether it computes the same function as the component it replaces, and the memory traffic the analytical model predicts for it, relative to that component, before any measurement.

**Table 9.** Candidate substitutions, the cost mechanism each targets, and its predicted memory traffic relative to the component it replaces

| Component (quadrant) | Cost mechanism | Substitution | Same function | Predicted memory traffic | Source |
|---|---|---|---|---|---|
| Positional encoding (priority: high waste, low capability) | Six separate elementwise operators, each reading and writing the queries and keys | Rotary encoding compiled into one forward and one backward kernel | Yes | 0.29 times | Hsu et al. (2024) |
| Positional encoding (priority: high waste, low capability) | As above | Removal of positional encoding | No | None | Haviv et al. (2022); Kazemnejad et al. (2023) |
| Layer normalization (priority: high waste, low capability) | Every activation read and written for a few operations per element, 2L + 1 times per pass | RMSNorm as separate operators | No (RMSNorm) | 6.0 times | Zhang and Sennrich (2019) |
| Layer normalization (priority: high waste, low capability) | As above | RMSNorm as one fused kernel | No (RMSNorm) | 1.0 times | Zhang and Sennrich (2019); Hsu et al. (2024) |
| Input embedding lookup (priority: high waste, low capability) and output projection (comparison) | A full-width table row read for every token; a full-width projection onto the vocabulary | Factorized embedding and unembedding through 128 dimensions | No | 0.61 to 0.90 times (both sides) | Lan et al. (2020); output side: this study |
| Attention core (comparison; high waste, high capability) | The full score matrix written to and read from memory across mask, softmax and weighting | Memory-efficient fused attention | Yes | 0.03 to 0.19 times | Rabe and Staats (2021); Lefaudeux et al. (2022) |
| Attention core (comparison) | As above | Causal linear attention | No | 0.19 to 1.45 times | Katharopoulos et al. (2020) |
| Attention projections (comparison; low waste, low capability) | None identified: compute-bound in every configuration | Grouped-query attention with a quarter of the key and value heads | No | 1.04 to 1.13 times | Ainslie et al. (2023); Shazeer (2019) |

*Note.* Predicted memory traffic is the analytical bytes moved by the substitute in one forward and backward pass, over the whole model, divided by those of the component or components it replaces, over the eighteen configurations; it is a prediction, not a measurement. "Same function" means the substitute computes the same output as the original. RMSNorm differs from LayerNorm by dropping the mean subtraction and the bias. The output-side factorization has no published counterpart and is this study's extension of ALBERT's input factorization.

**Priority components.** For positional encoding, the waste comes from how the rotation is implemented: in the baseline it runs as six separate operators, each of which reads the queries and keys from memory and writes them back. The fused rotary kernel computes the same rotation in a single pass over each of the queries and keys, which the analytical model predicts moves 0.29 times the bytes and performs half the counted operations. On the T4 the compiled version ran as exactly two kernels, one for the forward and one for the backward pass, confirming that the fusion took place. Removing positional encoding goes further and removes the component's energy entirely, at a quality cost known only from published evidence. For layer normalization, the baseline already runs as a single fused kernel, so there is no eager overhead for a better implementation to remove; the candidates instead change the algorithm. RMSNorm removes the mean subtraction and the bias. Written as separate operators, as in common open-source implementations, it is predicted to move six times the bytes of the fused LayerNorm, because each operator makes its own round trip to memory; as one fused kernel it moves the same bytes as LayerNorm with 0.57 times the operations. The pair therefore separates the algorithm (RMSNorm against LayerNorm, both fused) from the implementation (fused against separate operators). For the input embedding lookup, the factorized embedding reads a 128-wide row instead of a full-width one and adds a small matrix multiplication, which the analytical model predicts moves 0.25 to 0.42 times the bytes of the lookup. The same factorization applied to the output projection is predicted to move 0.70 to 0.93 times its bytes and to perform far fewer operations; this output side has no published counterpart.

**Comparisons.** The attention core's waste comes from the score matrix, which the unfused baseline writes to memory and reads back at each step. The memory-efficient kernel computes the same attention in tiles without storing the full matrix, recomputing it in the backward pass, and is predicted to move only 0.03 to 0.19 times the bytes. It also changes the core's roofline class: it is predicted to be compute-bound in 12 of the 18 configurations, memory-bound only in FP16 at 512 and 1,024 tokens. Linear attention replaces the softmax with a feature map and carries a running state across chunks of 64 tokens, computing a small masked score block only within each chunk. It changes the function, its predicted traffic ranges from 0.19 to 1.45 times the original depending on the configuration, and it stays memory-bound everywhere. Grouped-query attention reduces the number of key and value heads in the projections, which are compute-bound and carry no positive waste, and it is predicted to move slightly more bytes than the original (1.04 to 1.13 times), because the shared keys and values are copied to every head.

### Discussion

The matching answers the fourth research question with a specific candidate for every priority component. For positional encoding and the attention core, the most direct candidates are not new architectures but different implementations of the same computation; for layer normalization and the embeddings, the candidates change the function. For positional encoding, the profile is consistent with the waste coming from running a simple rotation as several separate memory round trips, a hypothesis the fused kernel tests directly. For layer normalization, the fused RMSNorm was added so that a change of algorithm and a change of implementation could be told apart. Of the techniques surveyed in Chapter I, the ones most often proposed for efficiency target other costs: grouped-query and multi-query attention principally target the key-value cache during inference (Ainslie et al., 2023; Shazeer, 2019), and here they act on the attention projections, which the profile places in the low-waste quadrant; linear attention changes what the attention core computes, which the capability overlay advises against for a high-capability component.

The analytical predictions in Table 9 were computed from the architecture alone, independently of the energy measurements, and the fifth research question compares them with the measured savings. If the roofline account of the waste is right, the substitutions that remove most of the memory traffic of a memory-bound component, the fused rotary kernel and the memory-efficient attention, should save energy. RMSNorm as separate operators moves six times the bytes of LayerNorm, and its measured cost in the first full run is what prompted the fused version, which moves the same bytes as LayerNorm with fewer operations. Grouped-query attention adds traffic to a compute-bound component while reducing its arithmetic to 0.63 times, so its energy effect depends on the arithmetic rather than the traffic.

The candidate set has three limits. It was fixed largely before profiling, with three substitutions added after it (the fused rotary kernel, the removal of positional encoding and the fused RMSNorm), so it is not an exhaustive search of the catalog for each component. Each technique is represented by one variant (128 dimensions for the factorized embedding, a quarter of the key and value heads, chunks of 64 tokens for linear attention), so the results describe those settings rather than the technique in general. And each substitution is evaluated alone; the combined effect of applying several together is outside the design.
